# OPTIFY
Optify is a collection of frontend React projects showcasing interactive UI components and practical web application features. This repository includes an Image Slider, a To-Do List app, and a React Calculator, demonstrating key concepts in React such as state management, event handling, and responsive design.


## Projects Included
 # 1. Image Slider
Smooth transitions and animations

Responsive design for different screen sizes

Customizable controls for navigation

# 2. To-Do List
Add, edit, and delete tasks

Persistent storage using localStorage

Keyboard support for quick task entry

# 3. React Calculator
Basic arithmetic operations

Dynamic button inputs and clear/reset functions

Clean and modern UI


Technologies Used
React

JavaScript (ES6+)

CSS / Tailwind CSS (if applicable)

LocalStorage API
