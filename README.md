# 🌟 OPTIFY

Welcome to **Optify** – a curated collection of interactive frontend React projects designed to enhance your web development skills and showcase stunning UI components. Whether you're here to learn, get inspired, or contribute, Optify offers hands-on examples to elevate your portfolio!

---

## 🚀 Projects Included

### 1️⃣ Image Slider
- ✨ Smooth transitions & animations
- 📱 Responsive design for all screen sizes
- 🛠️ Customizable navigation controls

### 2️⃣ To-Do List
- 📝 Add, edit, & delete tasks effortlessly
- 💾 Persistent storage using `localStorage`
- ⌨️ Keyboard shortcuts for quick task entry

### 3️⃣ React Calculator
- ➕➖✖️➗ Basic arithmetic operations
- 🖱️ Dynamic button inputs & clear/reset functions
- 🎨 Clean, modern, and intuitive UI

---

## 🛠️ Technologies Used
- **React**
- **JavaScript (ES6+)**
- **CSS / Tailwind CSS**
- **LocalStorage API**
